# Extraction benchmark

How well Corral's autofill reads rental listings, measured on a labeled dataset of fictional IV/Goleta listings. Generated by `npm run eval` from `eval/cases.ts`; see [`eval/README.md`](README.md) for the method.

- **Run:** 2026-11-16 · model `gpt-5-mini` · prompt `88be5b1faec0` · dataset `990240c3e0db`
- **Cases:** 40 text listings (16 held-out test, 24 dev), 15 of them also as phone screenshots (7 test)
- **AI runs:** 3 repeats per case (the model isn't deterministic; ranges show min–max) · screenshots at `high` detail
- **Cost** is computed from the tokens the API reported, at $0.25 / $2 per million input / output tokens (OpenAI list price for gpt-5-mini, Aug 2025).

**Reading the numbers:** *field accuracy* counts every scored field (address, link, rent, beds, baths, lease start and end, parking, laundry), including correctly left-empty ones. *Hallucination rate* is the share of fields the listing doesn't state that the extractor filled in anyway; *miss rate* is the share of stated fields it left empty. Counts are small, so a single field moves a percentage noticeably.
